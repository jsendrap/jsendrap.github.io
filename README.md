# Juana Sendra Pons · Academic website

Personal academic website of Dr Juana Sendra Pons, Associate Professor (Profesora Titular) in the Department of Mathematics, CUNEF Universidad.

Plain static HTML and CSS, with no build step. GitHub Pages serves it as is.

## Pages

| File | Tab |
|---|---|
| `index.html` | About |
| `journal-articles.html` | Journal Articles |
| `chapters.html` | Chapters & Proceedings |
| `books.html` | Books |
| `talks.html` | Talks |
| `projects.html` | Projects |
| `supervision.html` | Supervision |
| `service.html` | Service |
| `outreach.html` | Outreach |

Shared styles are in `style.css`. `site.js` draws the rotating curve figures on the About page and runs the "Copy email" button.

## Changing the photo

Upload a new picture named `photo.jpg` to replace the current one.

## Adding a publication

Open `journal-articles.html`, copy an existing `<li>…</li>` block in the list and change the year, title, authors, journal and DOI.
